# Product Direction Skills

This collection defines the durable product intent that market research, Wardley Strategy, portfolio decisions, and initiatives must be able to challenge as well as support.

## Included Skill

### `product-direction`

Creates or revises the canonical direction artifact: purpose, desired future, target context, strategic outcomes, principles, boundaries, measures, assumptions, and review triggers. It is not a roadmap, a feature backlog, or a substitute for market research.
